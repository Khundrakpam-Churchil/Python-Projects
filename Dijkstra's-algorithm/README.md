# Network Simulator with Dijkstra's Algorithm

Simple console-driven network simulator demonstrating Dijkstra's algorithm, visualization, and import/export.

Run:

```bash
python cli.py
```

Dependencies: see `requirements.txt` (install with `pip install -r requirements.txt`).

Demo:

```bash
python run_demo.py
```

This will load `sample_network.json`, run Dijkstra, apply link failures and congestion, and write `demo_output.json/csv/xml`.
